```
💧 워터링이 더 꼼꼼해졌어요!

🎯 위젯으로 기록한 뒤 앱을 다시 열었을 때, 안 마신 물을 마신 것처럼 뜨던 성취 카드 오류를 고쳤어요.
⭐ "이 앱 리뷰하기" 버튼을 눌러도 반응이 없던 문제를 고쳐서, 이제 누르면 바로 스토어로 이동해요.
🔒 내부 라이브러리 보안 업데이트도 반영했어요.

더 정확하고 믿음직한 워터링으로 오늘도 물 한 잔 어때요? 💙
```

## 포함된 변경사항 (v1.0.7 업로드 이후 커밋 기준, 내부 참고용)

- 위젯 탭으로 기록 후 앱을 재설치하면 안 마신 물을 마신 것처럼 성취 카드가 뜨던 버그 수정 (Android Auto Backup이 위젯 전용 대기 플래그까지 복원하던 문제 — 이제 별도 파일로 분리해 백업 제외)
- Play 스토어 정식 설치본에서 "이 앱 리뷰하기" 버튼이 무반응이던 버그 수정 (인앱 리뷰 API 쿼터 초과 시 조용히 실패하던 경로를 우회, 이제 스토어 리뷰 페이지로 바로 이동)
- androidx.glance 1.1.0 → 1.1.1 업그레이드 (protobuf 관련 보안 취약점 CVE-2024-7254 해소, 사용자 체감 변경 없음)
