# 출시 노트 — v1.0.6 (versionCode 7)

> Play Console 비공개 테스트 트랙 "새 버전 만들기" 제출 시 그대로 붙여넣기. 캐주얼 톤, 500자 이내.

```
💧 더 정확해진 워터링으로 돌아왔어요!

🛡️ 연속 기록 보호권, 월 1회 → 2회로 늘렸어요. 통계 화면에서 이번 달 사용 횟수도 바로 확인할 수 있어요.
✅ 목표 달성 판정을 더 정확하게 다듬었어요 — 컵 크기·목표를 바꾸거나 백업을 복원해도 연속 기록이 정확하게 계산돼요.
🔄 기록을 취소하면 건강 연동(Health Connect) 데이터도 함께 깔끔하게 정리돼요.

작은 오차 하나하나까지 신경 썼어요. 오늘도 물 한 잔 어때요? 💙
```

## 포함된 변경사항 (v1.0.5 업로드 이후 커밋 기준, 내부 참고용)

- 목표 달성 판정을 기록 개수 대신 ml 비례 크레딧으로 전환 (소량만 기록해도 달성 처리되던 문제 수정)
- 목표를 낮췄다 올리는 것만으로 연속 기록이 부당하게 늘어나던 문제 수정
- 컵 크기 변경 시 옛 컵 크기 기준으로 달성이 오판정되던 문제 수정
- 백업 복원 시 연속 기록 미검증 + 빠른 취소(undo) 시 롤백 누락 수정
- 체중 기반 목표 설정 시 진행률이 역전되던 버그 수정
- 기록 취소/초기화 시 Health Connect에 남아있던 기록이 함께 삭제되도록 수정 + 소소한 타이밍 이슈 2건
- 연속 기록 보호권 월 1회 → 2회 완화 + 롤백 버그 근본 수정
- **연속 기록 보호권 UI 노출 신규**: 통계 화면 전용 카드("이번 달 N회 사용 · M회 남음") + 발동 시 홈 배너
