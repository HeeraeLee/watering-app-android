## 포함된 변경사항 (v1.0.6 업로드 이후 커밋 기준, 내부 참고용)

- 온보딩 컵 크기 옵션을 설정 화면 실제 프리셋과 통일 (불일치로 혼란 유발하던 버그 수정)
- 수분 환산율(hydrationRate) 사용자 고지 추가
- 위젯 추가 화면 미리보기가 앱 아이콘으로만 뜨던 버그 수정 + 영어(en) 리소스 추가
- Jacoco 코드 커버리지 도입 및 Service/Repository/ViewModel 레이어 단위 테스트, Compose UI 테스트(8개 화면) 대폭 확충 (내부 품질 강화, 사용자 영향 없음)
